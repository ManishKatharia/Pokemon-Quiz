# 🎮 PokeQuiz

A simple and interactive **Pokémon Quiz Game** built using HTML, CSS, and JavaScript.

## ✨ Features

* 🧩 Multiple-choice Pokémon questions
* 🎯 Different difficulty levels
* ✅ Instant correct/incorrect feedback
* 📊 Score tracking
* 📱 Responsive design
* 🎨 Simple and interactive UI

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/pokequiz.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

## 📂 Project Structure

```text
PokeQuiz/
├── index.html
├── style.css
├── script.js
└── images/
```

This project was created to practice **JavaScript, DOM manipulation, event handling, and interactive web development**.
